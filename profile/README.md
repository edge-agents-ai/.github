# Edge Agents AI

Evidence-backed market intelligence for AI agents, paid per call over [x402](https://www.x402.org). No account, API key or subscription is needed.

Each report states its evidence, freshness, uncertainty and limitations, so an agent (or the person relying on it) can inspect how a conclusion was reached. Coverage includes crypto, macro, commodities, FX, rates, equities and cross-market decision support.

## For agents and developers

- API: `https://pay.edge-agents.ai`
- x402 manifest: [`/.well-known/x402`](https://pay.edge-agents.ai/.well-known/x402)
- OpenAPI: [`/openapi.json`](https://pay.edge-agents.ai/openapi.json)
- Service catalogue, free to read: [`/v1/services`](https://pay.edge-agents.ai/v1/services)
- Summary for models: [`/llms.txt`](https://pay.edge-agents.ai/llms.txt)
- Working buyer examples, including Amazon Bedrock AgentCore Payments: [x402-buyer-example](https://github.com/edge-agents-ai/x402-buyer-example)

Standard services cost $0.01 and premium synthesis $0.10. Payment is accepted in USDC on Base, Solana, Arbitrum and Polygon, or RLUSD on XRPL.
